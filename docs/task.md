# Задание на курсовую работу
## Дисциплина: ООП
## *Тема: Информационная система управления игровой фракцией*
### Технологии
- Язык программирования: C#.
- Интегрированная среда разработки: Microsoft Visual Studio.
- Фреймворк: .NET Framework или более новая версия.
- Тип приложения: WPF-приложение либо веб-приложение на C#
### Ограничения
1. Консольные приложения/приложения на WinForms в качестве курсовой работы не
   принимаются. Используйте WPF, либо веб-приложения ASP.NET
2. Нельзя использовать какой-либо язык программирования помимо C# без
   предварительного согласования с преподавателем, принимающим курсовую
   работу.
3. Нельзя выполнять групповой проект без предварительного согласования с
   преподавателем, принимающим курсовую работу.
4. При обнаружении явных признаков несамостоятельного написания кода
   (например, помощь другого человека или использование искусственного
   интеллекта) оценка за курсовую работу может быть снижена либо аннулирована.
   Функциональность приложения
   Ваша задача состоит в разработке приложения, соответствующего выбранной теме и
   демонстрирующего применение принципов объектно-ориентированного
   программирования.

### Приложение должно выполнять следующие функции:
1. В приложении должны быть реализованы CRUD-операции с данными:
   * o добавление новых данных;
   * o просмотр данных;
   * o изменение существующих данных;
   * o удаление данных.
2. Данные приложения должны сохраняться в постоянном хранилище. В качестве
   хранилища может использоваться файл либо база данных. После завершения
   работы и повторного запуска приложения ранее сохраненные данные должны быть
   доступны пользователю.
3. Функциональность приложения должна соответствовать теме и обеспечивать
   возможность полноценной работы пользователя с основными сущностями
   приложения.
4. В проекте должны использоваться все конструкции и инструменты языка C#,
   изученные в рамках лабораторных работ, а также принципы объектно-
   ориентированного программирования.
5. Студент должен владеть знаниями об используемых инструментах и принципах
   ООП и в ходе защиты уметь объяснить, каким образом они реализованы в его
   приложении, для чего используются отдельные классы, методы, свойства и другие
   конструкции, а также обосновать принятые при разработке решения.
   

### Примеры проектов
   - Ниже приведены примеры возможной функциональности курсового проекта.
   Приведенные варианты являются примерами и не ограничивают выбор предметной
   области.
1. Управление списком животных в зоопарке:
   • Добавление новых животных с указанием их видов и особых характеристик;
   • Удаление животных из списка;
   • Просмотр списка всех животных;
2. Управление списком сотрудников зоопарка:
   • Добавление новых сотрудников с указанием их должности, имени и контактной
   информации;
   • Удаление сотрудников из списка;
   • Просмотр списка всех сотрудников;
3. Расчет стоимости посещения зоопарка для посетителей:
   • Учет стоимости по типу билета (взрослый, детский, скидочный);
   • Учет стоимости дополнительных услуг (экскурсия, кормление животных,
   фотосессия);
   • Генерация квитанции с указанием общей стоимости посещения.
4. Система управления библиотекой:
   • Добавление новых книг с указанием названия, автора, жанра и года издания;
   • Изменение информации о существующих книгах;
   • Удаление книг из списка;
   • Просмотр и поиск книг;
   • Добавление и редактирование информации о читателях;
   • Учет выдачи и возврата книг.
5. Система учета товаров на складе:
   • Добавление новых товаров с указанием наименования, категории, количества и
   стоимости;
   • Изменение информации о товарах;
   • Удаление товаров;
   • Просмотр и поиск товаров;
   • Учет поступления и списания товаров;
   • Расчет общей стоимости товаров и формирование информации об остатках.
### Структура текста курсовой работы (пояснительная записка)
1. Введение (Краткое описание проекта, цели и задачи).
2. Анализ требований (Описание функциональности и основных требований к
   приложению).
3. Проектирование (Проектирование классов и взаимодействия между ними
   согласно принципам ООП).
4. Реализация (Описание реализации каждого класса и функциональности).
5. Тестирование (Описание проведенных тестов и результатов).
6. Заключение (Обобщение результатов, описание полученного опыта).
   Требования к оформлению
1. Тема должна начинаться с «Разработка…», например Разработка информационной
   системы для зоопарка, Разработка веб-приложения для покупки билетов.
2. Каждый класс должен быть оформлен в отдельном файле с именем,
   соответствующим названию класса.
3. Классы должны быть описаны с использованием принципов ООП: инкапсуляция,
   наследование, полиморфизм.
4. Код должен быть написан с использованием принятых конвенций и стандартов
   языка C#:
   o Отступы: 4 пробела;
   o Именование: CamelCase для методов и свойств, PascalCase для классов;
   o Комментарии: добавьте комментарии, чтобы пояснить назначение классов,
   методов, свойств и т.д.
5. В проекте должны использоваться изученные в рамках лабораторных работ темы и
   конструкции ООП, включая классы, структуры, модификаторы доступа,
   виртуальные методы, абстрактные классы, наследование, полиморфизм,
   обобщения и обработку исключений.
6. Необходимо предоставить документацию с пояснениями о работе приложения и
   описанием используемых классов, методов и свойств.
7. В рамках защиты курсовой работы студент должен продемонстрировать
   работоспособность разработанного проекта и представить пояснительную записку
   к нему — текст курсовой работы, оформленный в соответствии с требованиями
   ГОСТ.
8. Студент должен быть готов продемонстрировать основные сценарии работы
   приложения, работу с сохраненными данными, а также ответить на вопросы по
   исходному коду и использованным в проекте принципам объектно-
   ориентированного программирования.
   Дополнительные требования для обучающихся на
   направлении «геймдев»
   • Добавьте в приложение дополнительную функциональность, связанную с игровой
   тематикой (например, возможность покупки билетов на фэнтезийное шоу или
   просмотр анимаций животных).
   • Обращайте внимание на пользовательский интерфейс, включая графический
   дизайн и удобство использования приложения для игроков.
   Критерии оценки курсового проекта
   Выполнение курсового проекта будет оцениваться на основе следующих критериев:
   • Корректная работа приложения согласно заявленной функциональности.
   • Реализация CRUD-операций и корректное сохранение данных между запусками
   приложения.
   • Применение изученных тем и концепций ООП при разработке классов и
   взаимодействии между ними.
   • Использование в проекте конструкций и инструментов, изученных в рамках
   лабораторных работ.
   • Понимание студентом исходного кода проекта, используемых инструментов и
   принципов ООП, а также способность объяснить их применение в ходе защиты.
   • Расширение базовой функциональности приложения в соответствии с выбранной
   специализацией.
   • Качество пользовательского интерфейса приложения.
   • Оформление исходного кода в соответствии с принятыми стандартами и
   рекомендациями.
   • Наличие и качество пояснительной записки, оформленной в соответствии с
   требованиями ГОСТ.
   • Соблюдение установленных требований и ограничений к выполнению курсового
   проекта
